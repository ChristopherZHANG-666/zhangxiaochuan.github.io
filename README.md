# ZHANG XIAOCHUAN | Editorial 

> A high-fidelity digital presence built with minimalist aesthetics and refined typography.

---

## 🕊️ Overview
This is the official repository for my personal portfolio. The design philosophy follows a **Luxury Minimalist** approach: prioritizing white space, elegant serif typography, and a seamless user experience.

## 📁 Sections
The website is structured into three primary editorial pillars:
*   **About**: An introduction to my professional philosophy and creative journey.
*   **Blog**: A collection of refined thoughts on technology, design, and excellence.
*   **Contact**: A direct portal for high-value collaborations and inquiries.

## 🛠️ Technical Stack
To ensure maximum performance and clean deployment, this project uses:
*   **HTML5/CSS3**: Hand-coded semantic structure.
*   **Google Fonts**: *Bodoni Moda* for editorial elegance and *Inter* for modern readability.
*   **GitHub Pages**: High-speed global hosting.
